Запропонувати мод

  1. Заповніть форму нижче й натисніть «Надіслати».
  2. Відкриється сторінка GitHub із готовим текстом. Увійдіть у свій акаунт (або створіть безкоштовний).
  3. Додайте ZIP мода й фото кнопкою «Add files» під полем опису.
  4. Натисніть зелену кнопку Submit new issue. Пропозицію побачать модератори.
Власник перевірить мод у грі й, якщо все добре, додасть його в каталог.
ZIP до 25 МБ можна додати файлом у вікні GitHub. Більший мод завантажте в хмару (Google Диск, Mega) і вставте посилання сюди.
Або додайте фото прямо у вікні GitHub: кнопка «Add files» чи вставте/перетягніть їх у поле опису.
