# FS23 ModHub (безкоштовна версія на GitHub)

Сайт-каталог + адмінка, яка працює з телефона. Сервер не потрібен, картка не потрібна.

- Сайт і `catalog.data` лежать на **GitHub Pages**.
- ZIP-файли модів лежать у **GitHub Releases**.
- Моди додаються через сторінку `admin.html` (вона сама оновлює каталог).

## Налаштування (один раз)

1. **Акаунт.** Зареєструйтесь на https://github.com (безкоштовно).
2. **Репозиторій.** Створіть новий репозиторій, наприклад `fs23-modhub`, **Public**, і поставте галочку «Add a README file» (репозиторій не повинен бути порожнім).
3. **Файли.** У репозиторії натисніть Add file → Upload files і завантажте:
   `index.html`, `admin.html`, `shared.js`, `config.js`, `mods.json`, `catalog.data`.
4. **config.js.** Відкрийте його в репозиторії (олівець для редагування) і замініть `ваш-логін-github` на свій логін. Назву репозиторію (`REPO`) змініть, якщо вона інша. Збережіть (Commit changes).
5. **Pages.** Settings → Pages → Source: *Deploy from a branch*, Branch: `main`, папка `/ (root)` → Save. Через 1–2 хвилини сайт відкриється за адресою
   `https://ВАШ-ЛОГІН.github.io/fs23-modhub/`.
6. **Токен.** https://github.com/settings/personal-access-tokens/new
   - Repository access: *Only select repositories* → ваш репозиторій
   - Permissions → Repository permissions → **Contents: Read and write**
   - Створіть і скопіюйте токен (`github_pat_…`). Не показуйте його нікому.
7. **Вхід.** Відкрийте `…github.io/fs23-modhub/admin.html`, вставте токен.

## Додавання мода

Адмінка → виберіть ZIP, заповніть назву, категорію, опис, додайте іконку й скріншоти → «Опублікувати».
Сайт оновиться за 1–2 хвилини.

Якщо браузер не зміг завантажити великий ZIP прямо в адмінці, завантажте його вручну:
репозиторій → Releases → Create a new release (тег `mods`) → прикріпіть ZIP → скопіюйте посилання на файл і вставте його в поле «або посилання на ZIP».

## Для гри

У клієнті гри (Lua) вкажіть адресу каталогу:
`https://ВАШ-ЛОГІН.github.io/fs23-modhub/catalog.data`

Формат каталогу такий самий, як у MobHub FS26 (`count=N`, `modN_title=`, …).
Номери модів `modN_` йдуть підряд від 0, після видалення мода номери наступних зсуваються. Для гри це нормально.

## Що треба знати

- Репозиторій має бути **Public**, інакше безкоштовний GitHub Pages не працюватиме.
- Картинки автоматично зменшуються до 1280 пікселів і стискаються.
- Файли в Releases до 2 ГБ кожен.
- Токен зберігається лише в браузері. Якщо втратите телефон, відкличте токен у налаштуваннях GitHub.
- Не залишайте `OWNER` зі значенням за замовчуванням: адмінка попросить його виправити.
- Публікуйте тільки ті моди, які автори дозволяють поширювати.
